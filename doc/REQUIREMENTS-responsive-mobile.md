## 0. 硬约束（违反即返工）

- **只动前端**（`internal/server/web/{index.html,app.js,style.css}`，必要时加纯样式文件）：不得改 HTTP 契约与接口字段（`POST /api/create`、`/api/text`、`/api/list`…）、不得改认证逻辑（三形态 TOTP / 密码 / 密码+TOTP）、不得改凭据存储策略（sessionStorage/localStorage + 7 天 TTL + 5 分钟短票）。
- **不引任何前端框架/依赖**（现有零依赖 vanilla JS + 手写 CSS 必须保持）。
- **不得回归已完成项**：新建空文件/文件夹弹窗、文本编辑、`#toast` 提示可见性（提示条必须仍可见：`display !== none`）。
- **桌面观感必须不变**：≥992px 逐像素一致（断点只在窄屏/`pointer: coarse` 生效）。
- 禁 emoji；文案克制；不隐藏导航（窄屏用抽屉/折叠）。
- 小步中文提交、不带署名、**不 push**；不 `git add` 二进制与构建产物。
- **部署顺序提醒**：`make check` 会重建 `dist/`（覆盖线上二进制）→ 构建前先备份；Hermes 负责部署，本任务**只改代码 + 跑门禁**。
- 禁止重启服务、禁止改 nginx/systemd、不许动 `/var/www`。

## 2. 要做的

1. **触摸目标**：窄屏/`pointer: coarse` 下工具栏与面包屑按钮 ≥44px、视图切换等图标按钮 ≥32×32、搜索框与表单控件 ≥44px 高且**字号 ≥16px**、相邻操作间距 ≥8px；桌面尺寸不变。
2. **字号**：4 处 11px 抬到 ≥12px；全仓 `font-size`（`rem`/`em`/百分比）扫一遍。
3. **窄屏排版**：工具栏按钮多时换行或折叠（不要横向滚动条）；文件名列不撑破容器（省略号 + `title`）；搜索框在窄屏占满可用宽度。
4. **登录页/新建弹窗**：窄屏单列、按钮通栏或 ≥44px、「记住我」复选框命中区 ≥44px。
5. **不回归**：`#toast` 仍可见、新建弹窗流程仍可用、文本编辑仍可用（改完自测走一遍）。
