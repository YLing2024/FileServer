# 安全模型

## 1. 威胁模型

局域网可信环境为主，但服务目录可能包含不可信内容（共享下载目录），
且监听地址可被局域网内其他人访问（默认 `0.0.0.0`）。主要防护：

- 路径穿越与目录逃逸；
- 符号链接逃逸；
- 可执行内容在服务源内以网页渲染（XSS/钓鱼）；
- 未授权访问（可选认证）；
- 隐藏文件意外暴露。

## 2. 路径安全（`safePath`）

所有 `path` 参数统一经 `safePath` 校验：

- 拒绝绝对路径、`..` 穿越、非法字符；
- 规范化后必须落在服务根目录内；
- 文件操作前再以 `filepath.Rel` 复核，防止 TOCTOU。

## 3. 符号链接

服务目录内的符号链接**只允许指向服务目录内**：

- `os.Stat` 解析后再次校验目标在根目录内；
- 指向外部的链接在列表/搜索/下载/缩略图/zip 中一律拒绝（404）。

## 4. 隐藏文件

- 默认隐藏 `.` 开头文件（`--hidden` 可开启）；
- 未开启时：列表、搜索、直链、缩略图、zip 全部一致拒绝——不存在
  "列表看不到但能猜路径下载"的旁路。

## 5. 内容类型与可执行内容

- 全局响应头 `X-Content-Type-Options: nosniff`（禁止 MIME 嗅探）；
- HTML/SVG/JS/XML 等可执行/可脚本扩展名强制 `attachment` 下载——
  即使攻击者能向共享目录写入文件，直链打开也只是下载，不会在
  FileServer 源内以 `text/html` 渲染执行脚本（配合 nosniff 双保险）；
- 预览仅对白名单类型开放（图片/视频/音频/PDF/文本/代码），
  文本/代码类型以纯文本方式展示（不执行）。
- **写入范围（本轮有限放开）**：仅允许「新建文本文件」与「编辑文本文件」两条
  写入路径，其余（删除 / 重命名 / 移动 / 上传 / 建目录）一律不做：
  - 仅白名单扩展名的文本可新建/编辑（`doc/api.md` 列出清单）；
  - `.html/.htm/.svg` 等可脚本化扩展名**不在**白名单内；
  - 可编辑大小上限 2 MiB（`--text-max-bytes` 可配），超限只可预览；
  - 写入走既有 `safePath` 穿越/符号链接防护，原子写（临时文件 + rename），
    失败不留半截文件；并发写入以版本标识（mtime+size）校验，冲突返回 409；
  - 直链下载行为不因可编辑而放宽：`.html/.js/.svg` 仍强制附件下载。

## 6. 认证（可选，默认关闭）

- 启动参数 `--auth-mode none|totp|password|password+totp`（默认 `none`，局域网敞开，
  行为与历史版本一致）；兼容用法 `--auth user:pass` 等价于 `password` 模式 + 预置口令。
- 首次启动且 `--auth-mode != none` 时，浏览器落地**引导页**：设置口令（≥ 8 位；
  `password`/`password+totp`）与绑定 TOTP（`totp` 必须绑定不可跳过；`password+totp`
  可跳过，跳过后退化为单因素并可随时补绑）。引导完成后自动转登录页。
- 登录支持「记住我」：不勾=会话 cookie（关浏览器失效，服务端 TTL 默认 12 小时，
  `--session-hours`）；勾选=持久 cookie（默认 30 天，`--remember-days`）。
- cookie 属性：`HttpOnly`、`SameSite=Lax`、`Path=/`；请求为 https 或 `--cookie-secure`
  时带 `Secure`。
- 凭据只存服务端产物于 `.FileServer/auth.json`（0600，原子写）：
  - 口令：自研 Argon2id PHC 哈希（`m=64MiB, t=3, p=4`，标准库自研，RFC 9106 向量校验）；
  - TOTP 密钥：**明文存储**（无主密钥可加密，取 0600 文件 + 目录受控，等价于 SSH
    私钥的保护级别；如需更强保护应在磁盘加密层解决）；
  - 会话/记住我 token：只存 `sha256` 哈希 + 过期时间，永不落明文。列表页也不显示明文。
- 恒定时间比较：口令走 Argon2 派生后 `subtle.ConstantTimeCompare`，TOTP 校验同理。
- TOTP 重放防护：**任何一次成功的 TOTP 校验（引导绑定或登录）都会把该时间步计入
  已用集合**；同一步内同码再次使用一律拒绝，且不早于已消费步的窗口内码失效。
  窗口语义固定为当前步 ±1 步可接受、±2 步拒绝（未用过的码），不在本轮改动。
- 引导提交的**原子性**：`POST /api/auth/setup` 先校验全部必需因素（口令强度、
  TOTP 验证码），全部通过才一次性持久化口令哈希 + TOTP 绑定 + 配置状态；任一失败
  返回 `400` 且不写入任何部分状态，避免「口令已存、TOTP 未绑」却显示配置完成的
  伪装双因素状态。
- 失败限速：按客户端 IP 阶梯锁定（连续 5 次失败 → 60s → 300s → 900s，到顶维持）。
  默认不信任代理头；`--trust-proxy` 时按 `X-Forwarded-For` **最左**一个作为客户端
  IP（方向写死，避免伪造右值绕过）。
- 认证响应不区分「用户不存在 / 口令错 / 验证码错」，统一 `访问凭据无效`；日志
  （含 `-v`）不打印口令/token/验证码，`/api/auth/*` 仅记录路径不记录查询串。
- 登录页/引导页响应带严格 CSP、`X-Content-Type-Options: nosniff`、
  `Referrer-Policy: no-referrer`、`Cache-Control: no-store`。

### 6.1 丢失验证器 / 口令的自救（命令行重置）

服务**未启动**时，用同一 `--dir`（默认 exe 所在目录）执行：

```bash
# 仅清除 TOTP 绑定，保留口令（丢失验证器时用）
FileServer --reset-totp

# 清除全部凭据与会话，重新进入引导（口令也忘了时用）
FileServer --reset-auth
```

> 安全提示：重置后**任何人都能重新引导绑定**（谁先设谁拥有）。请在**受信网络**
> 下操作，重置完成并重新配置前不要对外暴露端口。命令执行后进程直接退出，需重新
> 启动服务并在浏览器完成引导。

## 7. 其他

- 隐藏目录 `.FileServer` 不在列表中显示，且其内部文件不可通过 API 访问
  （`hiddenBlocked` 拦截）；
- zip 打包同样走 `safePath`/符号链接/隐藏校验；
- 服务端不执行用户提供的任何代码；ffmpeg 参数全部由服务端构造
  （文件名仅作为位置参数传入，不以 shell 执行——`exec.Command` 无 shell 注入面）；
- 下载文件名 `sanitizeFilename` 清洗（去路径分隔符/控制字符），
  Content-Disposition 正确编码中文。
